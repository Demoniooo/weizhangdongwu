## 与 storyboard 的差异（及原因）

1. **N3 机位**：`TR_KING2S` = cam(1300,560,1.45) 与上摇终点 cam(1320,470,1.4) 会让勇者（x=620）和书记官出画，而分镜要求“勇者在左边礼貌微笑、书记官划叉”。按“屏幕落点优先”改为 cam(1200,560,1.45) → cam(1220,505,1.4)。
2. **N4 圣旨出现方式**：分镜写 53.95 书记官从右边跑进来展开；但这时是勇者格（CU-H），圣旨左端就在勇者身边，提前画会穿帮。改为勇者格期间不画圣旨，54.00 急拉 + 闪白的同一帧露出已展开四成的圣旨，书记官在卷筒那端倒退着继续展开。
3. **N2 计数**：没有在 48.30 直接跳成「13/8」，而是随牌落下 9/8、10/8…13/8 一路变红往上数（与“新牌一块块硬挤进来”一致，更好读）。
4. **卫兵抛帽 → 双臂欢呼**：王座厅卫兵一直没有高帽（b04 设定 + 出场合同注明）。
5. **N4 站位**：圣旨在地上时，传令官（980）与左卫兵（1240）会挡住金字，N4 期间他们分别站到画左 (360,880) 与台阶顶 (1735,790)，书记官在卷筒端；55.95–56.53 欢呼着蹦回出场合同的站位。
6. **金印砸印**：国王站在“地上的圣旨”上（脚底 y=790，与台阶顶同高，脚下补接触影），印面落点 = 每段字的中心；`sealSlam` 的印面在身侧 130px，砸第二、三下后国王身体会暂时挡住「迪」「翁」的金字（屏幕上的三行印章字承担阅读）。
7. 气泡、王冠尖上的「翁」、K1/K2 背景碎片等次级细节按分镜意图自定（例如「翁」卡在王冠尖用世界坐标 62px 字、随王冠 `crownTop/crownRot` 走）。
