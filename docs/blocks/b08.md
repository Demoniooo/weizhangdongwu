## 2. 与 storyboard 的差异及原因

1. **容器“立体书式立起”**：storyboard 没写容器何时出现。接缝合同 b07|b08 里 b07 不画容器，而 90.00 时宝箱、陶罐已在橡树右侧画面里，所以容器改为在滑到屏幕 x≈1560 时从纸面折起来（outBack + 底边折痕 + 纸屑），正好在勇者到达前 1–1.5s 预告。
2. **村民比例与站位**：storyboard 3.2 旅途一律 s=1，但小屋的门只有 92 高，s=1 的村民比屋墙还高，改为 s=0.82；主人出门后往右让一步（+54，老爷爷 +215，软帽姑娘 +150，面包师 +90，0.95 层坐标），否则下巴掉地 / 晕倒那一刻正好被马头和容器挡住。村民都是 90.47 之后才推门出来（接缝帧不能多出人）。
3. **拔剑 / 收剑**：storyboard 只写“用剑尖挑开”。heroJourneyState 的 rideLean 每次会把剑在背上与手里之间切换（每 0.35s 一次），改为 91.62 拔剑一挥、整段 V10 剑平端在手里、每次开箱前剑尖压低再一挑、93.60 甩到脑后插回鞘（用 rideSlash act 0 的“手在脑后”掩护切换）。
4. **鸡横穿**：从画右冲进、斜穿路面从马头前跑过（91.05 = JOURNEY.events.chicken）再出画左，勇者低头看一眼。
5. **整帧后期**：村庄段严格用合同 `journeyFx(T)`；S / N / C 区（sat 0.7 / bright 0.9 / vignette 0.5 dragonDeep）按各区在画面里的宽度加权，随遮挡物扫过连续过渡，不在遮挡物中线处跳。
6. **增加的小戏**（不改任何时刻）：橡树落叶、金色浮尘、马被喷嚏吓一哆嗦抖掉积雪、月出山脊亮边与四角星、急刹刹车印、白马躲岩石时冒汗。

## 4. 已知问题（按严重程度）

1. **洞口獠牙会被 b09 的遮罩盖掉**：journey.js 的上排獠牙（钟乳石）画在杏仁轮廓里面，b09 在 98.60 起用同一轮廓填径向渐变时会把它们一起盖掉（98.60 那一帧獠牙消失）。建议 b09 在遮罩里重画獠牙或把遮罩向内收几像素（见第 5 节）。
2. **勇者被推镜甩在身后**：`heroJourneyX` 步行 175 px/s，到 99.60 只走到 x≈12407，推镜终点 13000 → 勇者约 99.48 出画左，镜头“越过”他钻进洞口。按共享函数如此，b09 开头勇者已在洞内左下，衔接上可读。
3. **骑乘起伏与步态不同步**：合同 `journeyRiderParams` 把勇者 phase 直接给成马的 x/280，没按 hero.md 5.3 乘 280/步幅（walk 90、trot 160），村庄段勇者颠簸比马步慢约 3 倍。为保证接缝一致照合同写，未在块内改。
4. **下马那 0.25s 略挤**：98.30–98.45 勇者从人立的马背滑下时与马头重叠一下。
5. **急刹后围巾垂成竖条**：98.30–98.50 936 长的围巾在静止时贴地堆着，短时间像一条红竖带。
6. 主人的位置不是 `JOURNEY.houses[].door` 原点（见差异 2）。

## 5. 需求（给基础模块 / 相邻块）

1. **b09（或集成）**：`src/env/journey.js` 的 `caveMouthPath` 内上沿 9 根獠牙 + 下沿 3 根小牙画在杏仁轮廓之内；b09 遮罩若只填渐变，98.60 起獠牙会消失。建议 b09 遮罩用 `caveMouthPath(c)` 向内收缩约 0.85 倍或遮罩里补画獠牙；另外 98.60 时本块的洞内是 `dragonDeep` 底 + magic(0.55–0.75 脉动)→dragon→ink 径向，b09 的渐变起始色接近它可避免一闪。
2. **`src/scenes/_seams.js` journeyRiderParams**：hero 的 `phase` 建议按步态换算（`h.phase * 280 / HORSE_GAITS[gait].stride`，hero.md 5.3），b07 / b08 同时生效；合同同时写明“V 区容器 b07 不画”（本块据此做了立起动画，若 b07 改为画容器，本块需去掉 `village.js` 的立起）。
3. **`src/rigs/hero.js` drawHero**：没有积雪参数，`heroJourneyState().snowCap` 只能在块内自己贴雪堆（`b08/rider.js` 的 `drawSnowCap`，按 颈→头 方向贴）。建议像 `drawHorse` 一样加 `snow: 0..1`（头顶 + 肩）。
4. **`src/ui/kit.js` bubble（jagged / cut 字）**：黄油体的「！」在 cut 样式里又细又小，本块改为字只写「阿嚏」+ `glyphIcon('exclaim')`；建议 bubble 遇到「！」「？」自动换成路径符号。
5. **`src/env/journey.js` heroJourneyState**：rideLean 每次开箱都在背剑 / 手握之间切换（k=0.5 处跳），本块用 `sword:'hand'` + `swordAngle` 覆盖；若别的块（b14 归程）也用到可考虑在状态里给 `sword` 字段。
