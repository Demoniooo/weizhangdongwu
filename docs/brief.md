# 《达拉崩吧》代码 MG 动画 MV —— 导演任务书（brief）

> 所有子任务都以本文件为准。时间一律用 `docs/cues.md` 的 cue（默认时间轴 = 原版 3:28.1）。
> 引擎与绘图 API 见 `docs/engine.md`。项目根目录：`/Users/erapi0neer/dalabengba-mv`。

## 0. 硬性约束

1. **纯代码动画**：Canvas 2D 程序化绘制，不用任何外部图片/视频素材。1920×1080 逻辑坐标，30fps 成片（2 倍超采样）。
2. **画面严格跟着歌词走**：每个 cue 的画面内容就是那一句在讲的事，关键动作要落在 cue 时间点上（误差 ≤0.15s）。只卡 cue，不做逐拍卡点（没有实测音频，节拍相位不可靠）。
3. **不内嵌歌词原文**：画面上可以出现的文字只有——四个长名字 + 王浩然（见 cues.md 末尾）、极短的对白/拟声（≤5 字，例如「再说一遍？」「是不是…」「对对！」「不对！」「嗷——」「叮！」）、我们自己写的界面字（「LV UP」「金币 ×12」「攻击 / 技能 / 道具 / 逃跑」「勇者招募」等）、听岔梗的五个名词标签（昆特牌、提琴、烤蛋挞、苏打、马拉松）、片尾署名。**不要把整句歌词做成字幕**（字幕由用户自备 LRC 另加）。
4. **确定性**：每一帧是时间 T 的纯函数（禁止 Math.random / Date.now / 跨帧累积状态），可以任意跳帧渲染。
5. **分镜连贯**：全片是一条连续的“纸上冒险”，不允许无动机的跳切和廉价交叉溶解（时间流逝除外）。

## 1. 风格：纸艺立体绘本 × 复古 RPG

- **世界是一本会动的纸艺立体书**：每个物体都是一片剪纸——平涂色块、边缘有极轻的手剪起伏、下面投一道柔和的纸片投影（离底面越高投影越大越虚）、表面有纸纤维纹理、顶部受光的切口有一道细亮边。景深靠“多平面”：远景层慢、主体层中速、前景层快且略虚化（经典多平面摄影台视差）。
- **RPG 是这个世界的“界面语言”**：对话框、名字牌、HP/EXP 条、LV UP 徽章、金币计数、回合制战斗菜单、宝箱、任务地图——但全部做成**纸艺质感**（奶油色卡纸 + 墨色描边 + 缝线/花边角饰 + 投影），不是像素风。
- **精致的标准**：配色克制统一（只用 `PAL` 调色板，见 engine.md）、每个画面有明确焦点与层次、光影有方向（左上主光，右下投影）、质感统一（纸纹+颗粒+暗角由引擎统一加）、运动全部有缓动和跟随、没有空白死帧、构图守安全边距（左右 96px、上下 72px）。

## 6. 运动原则

- 所有位移都要缓动（出场用 outBack/outExpo/spring 带过冲，入场前有预备动作）；匀速只用于持续行进。
- 跟随与余振：围巾、呆毛、王冠、龙尾、旗帜用阻尼振荡（`wobble`）或噪声驱动；落地挤压拉伸（`squash`）。
- 错峰：一组元素（字、人群、图标）入场要错峰 30–80ms。
- 机位永远不死：至少有轻微漂移（`drift`）；情绪点推近；冲击点震动（`shake` + `ctx.fx.shake`）；转场可用甩镜（whip pan + 运动模糊感速度线）。
- 冲击帧：打击/落地/盖章时 1–2 帧闪白（`ctx.fx.flash`）+ 放射线 + 震动。
- 粒子用 `burst / stream / field`（纸屑、火星、金币、雪、花瓣、灰尘、光点）。

## 7. 连贯手段（必须用上）

1. 绘本开合（开头翻开、结尾合上）。
2. 世界地图 + 红色虚线路线（立誓 → 间奏一 → 旅途小地图 → 归途）。
3. 屏幕方向一致：去程左→右，归程右→左。
4. 红围巾作为贯穿线索（可做“围巾擦屏”转场）。
5. 形状匹配剪辑：月亮↔金币、剑光↔星星、龙眼↔洞口、卷轴↔道路等。
6. 同一场景同一机位体系：角色比例统一（全景勇者高约 260px，中景约 420px，特写头部约 360px）。
7. 转场有动机：翻页、遮罩圈（圆形/星形/心形/钥匙孔）、物体擦屏（龙影、围巾、卷轴）、推镜穿越（钻进窗户/洞口/眼睛）、甩镜。

## 8. 技术要点（写分镜时要考虑可实现性）

- 可用：多层视差机位（`applyCam(g, cam, depth)`）、离屏图层（投影/纸纹/叠色/模糊）、遮罩（羽化/挖洞）、整帧后期（震动/推近/闪白/淡出/调色/宽银幕黑边）、无状态粒子、四套字体、纸艺路径（手剪椭圆、手剪多边形、平滑曲线、粗细笔触）。
- 一切形状由代码画：角色是“关节木偶”（部件绕枢轴旋转），场景是分层剪纸。复杂度要可控：同一地点/道具尽量复用。
- 镜头之间允许时间重叠做转场：**转场由后一个镜头负责画**，前一个镜头要在重叠期内继续正常绘制。
