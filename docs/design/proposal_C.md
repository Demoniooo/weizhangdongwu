# 《达拉崩吧》分镜 · 方案 C（制作设计 / 技术派）

> 依据：`docs/brief.md`、`docs/cues.md`、`docs/engine.md`。时间一律为默认时间轴（3:28.1）。
> 本方案的立场：**先定布景和木偶，再排镜头**。每个镜头都能落到“哪套布景 + 哪个标准机位 + 哪几个木偶动作 + 哪个界面组件”，拿着就能写代码；同一套东西反复用，越用越精。

---

## 1. 一句话视觉主张 + 核心卖点

**一句话主张：七套写死坐标的纸艺布景、五个关节木偶、一条红围巾——把整支 MV 做成一本可以反复拆装的立体 RPG 绘本：名字有多长，纸就有多长。**

核心卖点（8 条）：

1. **7 套布景 + 1 个纸剧场，全片 68 个镜头不出这 8 个地点**：绘本、城堡远景、城门广场、王座厅、地图、旅途长卷、龙洞（山顶段是它的外景变体）、纸剧场。每套布景的柱子、窗、王座、塔楼、洞口坐标写死（§4.6），谁接手都画在同一张“布景图”上，跨段落回到同一地点时观众一眼认得。
2. **“名字 = 实物长度”铁律**：每个长名字都变成一件有长度的实物（撑破的对话框 → 撑爆的取名框 → 歪塔 → 巨型印章字 → 13 节龙身 → 火焰字 → 名字之剑 → 13 座塔旗 → 念不完的卷轴 → 装不下的横幅）；短名字（达拉崩吧、米娅、王浩然）永远刚好装得下。
3. **三个 13 共用一个组件**：勇者名 13 字、龙名 13 字、城名 13 字。龙身 13 节、名字之剑 13 块、城墙 13 座塔全部走同一个“13 格字槽”组件 `glyph13`，写一次用五次。
4. **旅途一镜到底**：V04–V13 共 20 秒，一个 `journeyWorld()` 世界函数 + 一条 `journeyCam(T)` 机位曲线向右长卷，草原→村庄→雪口→月林→洞口按机位 x 自动换色，角落小地图同步走位；按 cue 切成 6 段给同一个作者写，段与段之间无缝。
5. **红围巾一根线穿全片**：封面书签 → 围巾擦屏出城 → 战斗扯破 → 风雪里横飞 → 名字之剑的缠柄 → 婚礼红绳 → 孩子的小围巾 → 合上书时露出的书签。围巾拖尾用“角色位置函数在 T−kΔ 取样”实现，纯函数可跳帧。
6. **零溶解：26 处转场全部有动机（§4.4）**，招牌手法 14 种：书页推入、闪光对位、告示背面即地图、推入城堡窗、卷轴翻页、围巾擦屏、洞口↔龙眼、金币↔月亮、碰撞星光↔星形遮罩、幕布开合、花瓣漩涡、圆窗推拉、名字卷轴↔道路、合书。
7. **一套纸艺 RPG 界面组件前后呼应**：国王 K1 的「再说一遍？」气泡在 Q1 被勇者原样用回；N2 的取名框在 O05 回来，只剩 3 格；V01 的角色卡在 V16 换成 BOSS 卡；所有组件同一奶油卡纸 + 墨线 + 缝线角饰。
8. **可分包、可并行**：7 个作者包（王座厅、龙洞再各拆成两半，共 9 份活）、每包基本对应一套布景（§4.7），镜头边界 = 布景边界，包与包之间只靠 7 类标准转场拼接，互不改对方代码。

## 3. 逐镜头分镜表

### 3.0 阅读约定

- **时间**：`L02@+0.7` = cue L02 默认秒 + 0.7s。区间 `[start, end)`；两镜重叠期 = 转场期，**由后一镜负责画转场**，前一镜照常画。
- **机位简写**：`TH-2S` 等见 §4.5 标准机位表（每套布景的固定 cam 值）。`→` 表示运动，括号内为缓动与用时。所有机位默认叠 `drift(amp 4–6)`。
- **景别**（brief §7.6）：W 全景 = 勇者高 260px（zoom 1）；M 中景 ≈420px（zoom≈1.6）；CU 近景 = 头部≈360px（zoom≈3.4）；ECU 大特写 zoom≥5。
- **深度**：远 0.3 / 中 0.6–0.8 / 主 1.0 / 前 1.3–1.5（前景 blur 2–4）。
- **图层数** = 本镜 `ctx.layer` 次数（天空底色、屏幕空间 UI、粒子直画不计）；上限 8。**风险**：低 / 中 / 高。
- **动作 ID**（H01、K03、D06…）见附录 A；**组件 ID**（UI-01…）见附录 C。
- 画面文字只出现：四个长名字 + 王浩然、≤5 字短对白/拟声、自拟界面字、听岔五名词、片尾署名。

**光向**：纸片投影一律向右下（摄影台顶灯在左上，`cut` 的投影偏移本来就是 +x/+y），**与故事里的光源无关**；月亮、火、彩窗这些故事内光源只通过 `glow / rays / tint` 表现。这样所有布景的纸片投影天然统一。

## 6. 最难做、最容易翻车的 5 个镜头及规避办法

### ① S25a–f 旅途长卷（80.10–100.10，20 秒一镜到底）
- **翻车点**：道具多、五个生态、六段拼接处跳帧；马蹄在地上“打滑”；颜色过渡发脏；小地图与画面进度对不上；性能掉帧。
- **规避**：一个 `journeyWorld` + 一条 `journeyCam`，六段只是按 cue 切开的调用区间，**段内不许有自己的机位逻辑**；奔跑循环相位 = 勇者世界 x ÷ 步幅（由位置解析得出，天然不打滑、纯函数）；只画视野内道具，Path2D 预建；混色只在区界 ±200 做 `smoothstep`，每区主色 ≤3；小地图 u 与世界 x 共用一张换算表；每层纸纹用 `texOffset` 跟随图层平移，避免纹理“贴在屏幕上”。自检：`sheet --from 80 --to 100.2 --every 0.25` 看拼缝与色带。

### ② S01 / S67 绘本开合 + 立体城堡（0–10.6、199.5–201.8）
- **翻车点**：假 3D 翻封面显得像“压扁”；二十多片立起的纸片节奏乱；S01→S02 的遮罩交接对不齐，城堡跳一下。
- **规避**：封面翻转 = scaleX(cosθ) + 按 cosθ 调亮暗的 `shade` + 书脊一条厚度带，过 0 瞬间换画内侧衬页；立体城堡直接调用 CASTLE 布景的 `popup[]` 参数（每片 0..1 立起进度），**S02 用的是同一个函数、同一套坐标**；`bookPageRect(T)` 由 S01 的机位函数导出，S02 直接 import；S67 用同一组函数把时间倒放。自检：10.20、10.40、10.60 三帧逐像素比对城堡位置。

### ③ S34 龙名第三遍：燃烧的环 + 冲镜头咆哮（117.60–121.20）
- **翻车点**：S 形到圆环的变形扭结；13 个字随切线转得倒过来不可读；龙头推到 zoom 2.2 后细节不够、纸边抖动被放大；火焰粒子过多掉帧。
- **规避**：龙身统一成“采样点数组”，任何姿态都是 N=64 个点，变形 = 逐点插值（不做拓扑变化）；字角度 = 切线角夹在 ±25°，环下半圈的字翻 180° 保持正立；龙头准备一个“近景细节档”（牙、舌、鼻孔纹路），推近时切换，描边宽随 `scaleOf` 反算保持屏幕线宽；每个喷火源 `stream` 限 60 粒/秒；图层 ≤5。自检帧：117.9、119.7、120.55、121.0。

### ④ S35–S40 间奏二动作戏（121.00–138.10）
- **翻车点**：纯动作段最容易“糊成一团”：看不清谁打谁、方向乱、闪白太多刺眼、劈火流的形状难看。
- **规避**：动作编排守三条——**每个动作都有预备、动作、收势；勇者永远在龙的左边；每 0.5s 至多一个动作**；全景与中景交替，中间插一段剪影（S37，最省也最清楚）；全段只有 5 次闪白（124.2、127.2、129.0、134.2、137.55），其余打击只用震动 + 放射线；劈火流 = 两条 `ribbon` 沿剑刃法线向上下分开、间隙随时间变宽，不做流体。先用灰色方块跑一遍 `sheet` 确认节奏再上细节。

### ⑤ S50 名字之剑（153.78–157.23）
- **翻车点**：13 个字从屏幕空间的名字牌飞到世界空间的剑上会“跳”；围巾缠柄穿帮；剑顶破帷幔的层级不对；zoom 0.85 拉出剧场外露出空白。
- **规避**：整段在同一个固定机位下完成，名字牌和剑都用剧场世界坐标（名字牌只是画在台框上的道具，不是屏幕 UI），不存在坐标系切换；13 个槽位写成常量表；缠柄 = 围巾 `ribbon` 沿螺旋线按 p 生长，分前后两半画在剑柄前后；剑单独一层、合成在台框层之上，帷幔“顶破”用一块预先剪好的翻片绕铰点转开；TT-out 用到的外围暗房与桌沿在布景里画足 2400×1350。自检帧：154.7、156.6、157.0。

### 附录 D 建造顺序与自检

1. **基础阶段**：`glyph13` → 7 套布景函数（先 THRONE、CAVE，出镜最久）→ 5 个木偶的姿势预设 → UI 组件 → FX-01～10。每样东西交付时附一张 `stills` 对照图。
