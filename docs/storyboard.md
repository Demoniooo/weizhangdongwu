### 0.3 已经解决的评审问题

- 符号一律用路径画：★ ♥ ♪ ✓ ✕ ✦ ▼ ▶ ①–④、箭头都不进字体（实测四套字体都没有）。间隔点「·」只有快乐体和 Fredoka 有，其余字体里用路径画的小圆点代替。

- 每个 cue 只定一个重音动作，落在 cue 后 0–0.15s；预备在前，余波在后（修正了 A 的 N4 盖章晚 0.4s、L08 晚 0.24s，A/B 的 V15 拔剑晚 0.5–0.7s）。
- K2 与 Q2 都有「是不是…」，与 K1/Q1 的「再说一遍？」构成国王格 / 勇者格的左右镜像。
- V14 先照出笼中撬锁的公主，再在勇者身后睁开巨眼。
- E01 勇者砍向锁时公主已从里面推开笼门。
- 「米娅」第一次出现在 O01；月亮第一次升起在 V12；“原来是一本书”的书桌只在开头和 O08 出现。

## 1. 视觉主张

**一本被名字撑爆的纸艺 RPG 立体书。一台多平面摄影机推进书里，沿一条红色虚线走完纸上王国，再退出书页，看着书被合上。**

1. **名字是有材质、有重量的实物**，每出现一次换一种材料、卷入的范围大一圈：对话框 → 取名面板 → 国王的肺 → 整个朝廷；龙身 → 火焰 → 石墙；剧场名字牌 → 名字之剑；花瓣 → 13 面塔旗 → 捷报卷轴 → 婚礼横幅包住城堡；最后王浩然的全名铺满通往天边的路。短名字（达拉崩吧、米娅、王浩然）永远刚好装得下。
2. **一条红线**：书签 → 拖地长围巾 → 立誓蜡笔路线 → 片名下划线 → 地图红虚线 → 吸收众人心愿 → 撕破 → 剪影里唯一的颜色 → 缠上名字之剑 → 擦屏开启归途 → 补丁 → 婚礼红绳 → 孩子的短围巾 → 书签。
3. **一套坐标**：每个地点的柱子、窗、塔、洞口写死；地图三种形态（蜡笔、羊皮纸、小地图）共用一组 (u,v)；13 座塔第一帧就立在那里，165 秒才揭晓。
4. **零溶解**：全片唯一的硬切在 18.00，而且是形状匹配（远去的龙缩成的红点 = 国王头顶「！」的圆点）。其余交接都是遮罩、擦屏物、甩镜或同机位隐形接缝。
5. **三大高潮**：间奏一片头（56.89–74.40）、名字之剑（153.46–157.80）、婚礼（176.80–185.47）。冲击强度在这三处封顶。

## 3. 全片规则

### 3.1 坐标与机位

- 世界坐标是该地点主体层（depth 1）的坐标；`cam(960,540,1)` 时与屏幕重合。机位写 `cam(x,y,zoom[,rot])`，运动写「A → B（缓动，起–止）」。
- 深度：天空 0（直画）｜远 0.25–0.4｜中 0.55–0.85｜主 1.0｜前 1.3–1.5（blur 3–5）｜界面 = 屏幕空间。
- 每个地点有一组**预设机位**（见第 4 节）。同一地点内换镜只能在预设之间运动；所有机位叠 `drift(amp 4–6, speed 0.35)`，只有 O02（世界变成插画）和 O04（时间流逝）两处锁死。
- **屏幕落点优先**：交接表里写的是交接物的屏幕位置/尺寸，机位数字与之冲突时，用 `toScreen` 反解机位。

### 3.3 景别、运动与冲击

- 景别：大全景 zoom 0.6–0.9 ｜ 全景 1.0 ｜ 中景 1.55–1.7 ｜ 近景 2.2 ｜ 特写 3.3–3.4 ｜ 大特写 ≥5。只有 BOOK、THEATER、CASTLE 允许 zoom < 1。
- 运镜：glide（常规）；snap（冲击推近，0.12–0.3s）；whip（甩镜 ≤0.35s，必须手画速度线）；outBack/spring（入场）；匀速只用于赶路。
- **反应格**（构图每次完全一样，重复就是笑点）：国王格 CU-K、勇者格 CU-H（王座厅、山洞各一组坐标）、巨龙格 CU-D。K1 与 Q1、K2 与 Q2 左右镜像：同姿势、同气泡样式、耳朵同样放大到 1.3 倍。
- 冲击帧分级（震动振幅 / 闪白）：小 6–10 / 0.2–0.3；中 12–18 / 0.4–0.6；大 20–26 / 0.7–0.9；**全片最大一次在 B11（震动 32，闪白 1.0 两帧）**。

### 3.4 方向

- 去程左→右，归程右→左。龙山永远在右侧地平线。
- 对峙轴线：勇者永远在画左；国王、巨龙、婚礼上的公主和国王都在画右。仅 O01 跳舞转圈临时换位，曲终换回；大战 I2 第二拍（盘柱）上下错位但左右不变。
- 龙的一切攻击物从右往左走（火、火焰字、尾扫、扑咬）；勇者的攻击从左往右走（刀光、名字之剑）。
- **名字一律从左往右读、按阅读顺序出现**；竖排只许从上往下。不允许倒着揭示。巨龙头在左、尾在右。
- 小蜥蜴：B12 诞生时面朝左（巨龙阵营），E02 爬上勇者肩头后改为面朝右，此后一直朝右。

### 3.5 画面文字与字形

- 字体分工：名字、标题 = `display`（黄油体）；对白、界面 = `play`（快乐体）；数字、LV、HP、VS、EXP = `latin`（Fredoka 600–700）；片尾署名 = `serif`（小薇）。
- 实测缺字：四套字体都没有 ★ ☆ ♥ ♡ ♪ ✓ ✕ ✦ ▼ ▶ ①–④ 及箭头，**一律用路径画**（`src/ui/kit.js` 的 `glyphIcon`）。「·」只在 play/latin 里有。Fredoka 没有中文标点，「！」「？」跟中文字体走。
- 名字逐字定格放置，不整串 `fillText`（便于逐字动画）。
- 可读性下限：名字每字屏幕 ≥ 48px，飞走、爆炸、变形前至少静止可读 0.25s（每遍的 c 段爆点可破例，但该遍 a、b 段必须读清）。
- 剪纸字标准：`lineJoin='round'` 奶油纸边（字号 × 0.18）→ 填色 → 图层投影。

### 3.6 安全区与字幕带

- 安全边距左右 96px、上下 72px（界面、名字、关键动作都在里面）。
- **字幕带**：有人声的段落（10.39–56.89、74.40–120.97、137.92–201.60）里 y ≥ 920 只放地面、脚灯、前景物这类装饰，不放名字和界面字。纯音乐段（前奏、I1、I2、尾奏）不受限。

### 3.7 计时

- 每个 cue 只定一个**重音动作**（砸、喊、立起、拔、弹出），落在 `cue@+0.00…+0.15`。预备动作放在 cue 之前，余波放在 cue 之后。
- 名字逐字时刻一律从 `NAME_TIMES`（`src/ui/type.js`）取：段首字 = 该段 cue，段内步长 = 段长 ÷ 字数。没有分段 cue 的句子按下表写死的分段计算。数值见附录 A。
- 走马灯：滚动偏移 = 窗口跨度 × 本 cue 已过时间 / 本 cue 时长（窗里永远是正在唱的那一段）。
- 纯音乐段（前奏、I1、I2、尾奏）在周深 Live 预设里会被拉长约 2 倍：动作链要落在清楚的姿态上并留保持，慢动作不低于 0.5 倍速。

### 3.8 转场与交接铁律

- **转场由后一块负责画**：后一块的 start 早于前一块的 end；重叠期内前一块照常画，后一块用 `ctx.mask` 揭示或在最上层画擦屏物（z: 1）。重叠 ≤ 0.5s（例外：b08→b09 洞口遮罩由推镜驱动，重叠 1.0s，期间 b09 遮罩里只画一层径向渐变，两块合计缓冲仍 ≤ 8）。
- **交接物铁律**：换地点时，负责转场的物体在交接瞬间，前后两块里的屏幕位置、尺寸、颜色完全一致（写在每块的「交接」里）。
- **隐形接缝**：同地点、同机位曲线的块边界不重叠，前块末帧与后块首帧像素一致。接缝两侧必须调用同一个布景函数、同一条机位函数（放在 `src/env` 或块共享常量里，不各写一份）。
- 隐形接缝不登记 `story.cuts`；全片 `story.cuts = [18.00]`。

### 3.9 性能预算

- 每帧（含重叠期两块相加）全屏缓冲 ≤ 8（`ctx.layer` + `ctx.mask` 各算 1，遮罩里再开图层再算 1）。离场块在重叠期可把远景合并成 1 层。
- 前景虚化层每帧 ≤1；单次 `burst` ≤150 粒，每个 `stream` ≤60 粒/秒；不逐形状 `shadowBlur`，纸片投影按图层给；不依赖引擎子帧运动模糊。
- 远处或很小的字（屏幕 < 6px）不逐字画，改画带点纹的纸带。

## 10. 风险与降级（每条都有退路）

1. **b13 名字之剑**（最高风险）：一切算在剧场固定坐标系里（第 i 块中心 x = 600 + 60 + 126·i），155.80 之前机位不动；台口拆成“剑后 / 剑前”两层，撕口用预剪好的多边形随剑尖长大；竖起时字已读过，用沿刃口上跑的扫光盖住转动；冲击只在 B11 做一次最大号。降级：不竖剑，横着向右一刀劈过（仍保留斩线与 B11 冲击）。验帧 154.8 / 155.6 / 156.4 / 157.1 / 157.2。
2. **b07–b08 旅途一镜到底**：事件按时间定，位置由时间反推；`journeyCam` 单调样条；每帧只画视窗外扩一屏内的区；每个换区点必须有遮挡物，过中线那一帧前后两区都画完整；月光段前景树干用手画速度条纹。验 `sheet --from 80 --to 99.6 --every 0.25`，逐 cue 看 ±0.15s。
3. **b01 立体书推镜交接**：立体件必须调用同一个 `drawCastle`（popup 全为 1 时与世界一致）；验 9.50 / 9.75 / 9.99 三帧，“只开 b01”与“b01+b02”逐像素对比。
4. **b15 婚礼**：横幅只绕主堡尖塔一圈（后半圈在尖塔后、前半圈在前，只有这一处前后遮挡）；字在展开阶段读完，绕塔时允许被挡；蝴蝶结是 184.70 单独弹出的道具。降级：不绕塔，两条横幅在尖塔顶交叉成心形再系结。
5. **b10 龙身 13 节与背板**：龙身统一为 64 点样条，任意姿态逐点插值；背板单独一层，旋转夹在 ±15°，字永远正立；所有点亮时刻取 `NAME_TIMES`。
6. **b11 大战**：先用灰色方块跑一遍 `sheet` 确认节奏再上细节；盘柱用“柱前 1.1 / 柱后 0.9”两层；分色只用两个半屏遮罩。降级：删掉第二拍盘柱，改成在龙背上直线奔跑踩字。
7. **b05 N2c**：同一时刻只让面板一件事当主角，每件事至少 0.25s；牌塔不做物理，全部关键帧。验 `--from 47.6 --to 49.5 --every 0.1`。

9. **字形**：画面文字只用第 3.5 节允许的字；符号一律路径画；验收时看有没有回退字体混进来。
